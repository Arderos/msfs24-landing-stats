# MSFS Landing Stats 0.9.5

## Добавлено

- Локальный API для сторонних приложений. Через Windows Named Pipes доступны история посадок, показатели отдельных касаний, записанные ряды, последние данные симулятора и состояние компонентов. Подписка сообщает о готовых результатах без ожидания упаковки диагностического архива; пропущенные события можно дочитать после переподключения. API выключен по умолчанию, включается в настройках; приложены [документация](integration-api.md) и [пример клиента на Python](examples/integration_client.py).

## Улучшено

- Полностью переработана архитектура приложения. Запись, анализ, хранение, интерфейс и доставка данных разделены на независимые модули. Подключение к симулятору, опрос контроллеров, анализ, отправка отчётов, Google Drive и внешний API работают в отдельных рабочих процессах.
- Добавлено автоматическое восстановление. Супервизор контролирует работу компонентов и перезапускает их при отказах. Журнал и контрольные точки позволяют восстановить доступное состояние записи, продолжить незавершённый анализ и доставить сохранённые отчёты после перезапуска.
- Каталог геометрии самолётов готовится в фоне. Отдельный процесс обновляет его после появления физики симулятора, один раз за подключение. Анализ посадки использует готовый кэш; изменения установленных самолётов учитываются при следующем подключении.
- Диагностические архивы стали компактнее. Добавлено сжатие Zstandard без потери данных с проверкой поддержки на сервере. Старые форматы записей и архивов продолжают приниматься.

## Исправлено

- Исправлены завершение соединения SimConnect и восстановление подписок телеметрии. Соединение освобождается после выхода из обработки сообщений, а отклонённые обязательные подписки запрашиваются повторно.
- Исправлена калибровка геометрии при сочетании крена и рыскания. Изменение касается производной реконструкции касания.
