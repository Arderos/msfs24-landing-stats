How to read these charts

Solid lines show the median; the inner band covers the 10th–90th percentiles. The optional outer band shows the minimum and maximum. These are pointwise statistics, not the trajectory of one real flight. Hover to see the number of independent approaches contributing to that point. Gold is the selected flight; thin clickable lines show up to the 50 newest approaches in each cohort.

Height profiles use the last downward crossing of each height before first contact. Time profiles use the recorded contact clock. Gaps over 0.5 seconds, paused or inactive physics, confirmed freeze/slew/SDK replay, and flight-segment changes are not interpolated. Hardware observations expire after 0.25 seconds; missing or ambiguous bindings remain gaps. Physical amplitude and timing are preserved; only recorded binding polarity is applied.

Each physical episode is counted once using its first contact. Heatmap counts give each approach one vote per cell. Metric colours show the median of available flight values in each cell; missing channels do not become zero. Trajectory density uses reduced display tracks. Filters use upload date and exact aircraft title. Recording app version is the Landing Stats version; aircraft add-on versions are not recorded. Cohort B changes the chosen criterion while retaining the other filters; an empty range bound is open.

At most the 250 newest matching approaches enter a comparison; the count above always states the scope. Display tracks are reduced; statistical profiles use original observations. AGL is the recorded aircraft reference height, so it need not be zero at touchdown. Coverage varies with the recording window and schema. Source-state coverage is shown in flight details; unavailable or stale evidence stays unknown. Contact-state bars show observed intervals; a saved impact window is the analysis duration, not a measured force-pulse width.
